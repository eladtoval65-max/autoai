# AutoAI — Live MVP

## פריסה ב־Vercel

הפרויקט הוא אתר סטטי עם Vercel Function אחת עבור הצ׳אט. חשוב להעלות את **תיקיית הפרויקט עצמה** או לחבר את תיקיית ה־GitHub שבה נמצאים `index.html`, `vercel.json` ו־`api/chat.js` בשורש.

ב־Vercel בחרו **Add New → Project**, העלו את התיקייה או חברו Repository, והשאירו את Framework Preset על **Other**. אין צורך ב־Build Command או ב־Output Directory. לאחר מכן הוסיפו ב־Settings → Environment Variables את `ANTHROPIC_API_KEY` לכל הסביבות שבהן תרצו להשתמש, ושמרו. אפשר להוסיף גם `ANTHROPIC_MODEL`, אך הוא אינו חובה.

לאחר שמירת המשתנים בצעו **Redeploy**. בדיקת הצ׳אט צריכה לפנות ל־`/api/chat`; המפתח נשאר בצד השרת ואינו נשלח לדפדפן.

## בדיקה מהירה

פתחו את כתובת האתר ש־Vercel נתן לכם. אם האתר נטען אך הצ׳אט מציג שגיאת AI, בדקו שהמשתנה נקרא בדיוק `ANTHROPIC_API_KEY`, שהוא הוגדר גם ל־Production, ושבוצע Redeploy אחרי הוספתו. אם מתקבלת שגיאת 404 ב־`/api/chat`, ודאו ש־`api/chat.js` נמצא בשורש הפרויקט ולא בתוך תיקייה נוספת שנוצרה בעת חילוץ ה־ZIP.

## מה כלול

הפרויקט כולל ממשק עברי responsive, זרימת התאמת רכב, כרטיסי המלצה, חישובי עלות, checklist, השוואה, שמירה מקומית, שיתוף, צ׳אט עם fallback מקומי ו־API server-side עבור Anthropic.

הנתונים בשלב זה הם נתוני הדגמה. לפני פרסום מסחרי יש להחליף אותם במקור נתונים מורשה ועדכני, ולהוסיף הגבלת קצב, אימות קלט, ניטור ועלויות שימוש.
